# 📖 Glossaire

Petit référentiel des sigles utilisés dans ce guide, pour une relecture rapide sans avoir à chercher ailleurs.

| Sigle | Signification | En une phrase |
|---|---|---|
| **DNS** | Domain Name System | Traduit un nom de domaine (google.com) en adresse IP |
| **DHCP** | Dynamic Host Configuration Protocol | Attribue automatiquement une adresse IP à un appareil qui se connecte |
| **VLAN** | Virtual Local Area Network | Sépare logiquement plusieurs réseaux sur les mêmes équipements physiques |
| **NAT** | Network Address Translation | Permet à plusieurs appareils de partager une seule adresse IP publique |
| **TTL** | Time To Live | Durée pendant laquelle une information (DNS notamment) reste en cache avant vérification |
| **VPN** | Virtual Private Network | Crée une connexion chiffrée entre un appareil et un réseau distant |
| **SIEM** | Security Information and Event Management | Centralise et analyse les logs de sécurité de plusieurs sources |
| **EDR** | Endpoint Detection and Response | Détecte et réagit automatiquement aux menaces sur un poste |
| **MDM** | Mobile Device Management | Gère à distance une flotte d'appareils mobiles (configuration, sécurité, effacement) |
| **BYOD** | Bring Your Own Device | Politique où l'employé utilise son propre appareil personnel à des fins professionnelles |
| **SELinux** | Security-Enhanced Linux | Système de sécurité renforcée sur certaines distributions Linux (RedHat, Oracle Linux) |
| **AD** | Active Directory | Service d'annuaire Microsoft gérant utilisateurs, ordinateurs et permissions |
| **BSOD** | Blue Screen of Death | Écran bleu d'erreur critique sous Windows |
| **DDoS** | Distributed Denial of Service | Attaque visant à rendre un service indisponible par saturation de trafic |
| **MITM** | Man-in-the-Middle | Attaque où un tiers intercepte une communication entre deux parties |
| **Zero-day** | — | Faille de sécurité connue publiquement avant qu'un correctif n'existe |
| **Phishing** | — | Tentative de tromperie par email pour voler des informations sensibles |
| **Smishing** | — | Même principe que le phishing, mais par SMS |
| **Vishing** | — | Même principe que le phishing, mais par appel téléphonique |
| **ADR** | Architecture Decision Record | Document qui trace le contexte et la raison d'une décision technique |
